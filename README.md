# Grande Bakery — Homepage Concept

A homepage concept for Grande Bakery, a family-friendly bakery café at Strathpine Centre and Logan Hyperdome, Brisbane.
Designed and built by Joseph Adeniji.

- Plain HTML, CSS and JavaScript, no build step
- Responsive desktop, tablet and mobile layouts with a mobile menu
- Tabbed "What's fresh" menu, contact form with topics, newsletter sign-up
- Load and scroll animations, with a reduced-motion fallback
- Optimised WebP images

Menu items are sample content. Photos are from Unsplash (free to use under the Unsplash License).
